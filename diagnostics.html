@echo off
title Complete PC Deep Diagnostics & Error Report Tool - Shri Raghav Tech
echo ========================================================
echo 1. Launching Windows System Diagnostic Report (Perfmon)...
echo ========================================================
perfmon /report

echo.
echo ========================================================
echo 2. Running Windows System Image Repair (DISM)...
echo ========================================================
DISM /Online /Cleanup-Image /RestoreHealth

echo.
echo ========================================================
echo 3. Running System File Checker (SFC /scannow)...
echo ========================================================
sfc /scannow

echo.
echo ========================================================
echo 4. Generating Power & Battery Efficiency Report...
echo ========================================================
powercfg /energy

echo.
echo ========================================================
echo Diagnostics Complete! Check your Perfmon HTML report window.
echo Note: For deep disk error repair, run 'chkdsk C: /f /r /x'
echo ========================================================
pause

Run perfmon /report

Press Win + R, type perfmon /report and hit Enter.

STEP 2

Wait 60 Seconds

Windows collects hardware, OS, memory & driver telemetry in background.

STEP 3

Inspect System Errors

Review Warnings, Failed Devices, Memory Leaks & Disk errors in HTML report.
