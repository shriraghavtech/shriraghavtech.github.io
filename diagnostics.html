OS Product Key Finder CMD Tool

This tool provides official terminal commands to retrieve embedded OEM Product Keys from motherboard UEFI ACPI MSDM tables for Windows, Linux, and macOS.

powershell "(Get-WmiObject -query 'select * from SoftwareLicensingService').OA3xOriginalProductKey"

sudo xxd /sys/firmware/acpi/tables/MSDM | tail -n 1 | awk '{print $10}'

sysctl hw.model hw.serialnumber && ioreg -l | grep IOPlatformSerialNumber
